# Student Performance EDA 📊

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on student performance data using Python.

The main objective is to understand student academic performance and identify factors that are associated with final grades.

## 🎯 Objectives

- Understand the student performance dataset
- Check the structure and quality of the data
- Analyze final student grades
- Study the relationship between study time and grades
- Analyze the effect of previous failures
- Study the relationship between absences and final grades
- Compare performance based on gender
- Analyze the relationship between parental education and student performance
- Identify important factors associated with final grades

## 📂 Dataset

The project uses the `student-mat.csv` dataset.

The dataset contains information about students, including:

- School
- Gender
- Age
- Address
- Family information
- Study time
- Previous failures
- Absences
- Previous grades
- Final grade

The final grade is represented by the `G3` column.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
